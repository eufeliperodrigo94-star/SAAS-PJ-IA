# PROJECT.md

SaaS de pré-validação de processos empresariais para contadores e escritórios de contabilidade,
com MVP inicial em Pernambuco.

- **Não substitui** Junta Comercial, Receita ou Redesim; não promete aprovação.
- Reduz retrabalho identificando erros, divergências e documentos ausentes antes do protocolo.
- Modelo comercial: assinatura mensal por escritório (Starter, Profissional, Escritório, Enterprise).

Ver `ARCHITECTURE.md`, `DATABASE.md`, `RULES.md`, `AI.md` e `TODO.md` para detalhes por área.
